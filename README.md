# drop-code

Drop: a small floating popup that sends exam papers / starter projects to a local Ollama model.

## Mac
1. Install Ollama and run `ollama pull qwen3-coder`
2. Put `install-drop.sh` and `Drop.icns` in `~/Downloads`
3. Run `bash ~/Downloads/install-drop.sh`

## Windows
1. Install Ollama for Windows and run `ollama pull qwen3-coder`
2. Open the `windows` folder and double-click `Install Drop.cmd`
